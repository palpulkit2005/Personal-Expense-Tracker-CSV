# Personal Expense Tracker with CSV

## Project Description
The Personal Expense Tracker is a Python-based application that helps users record and manage their daily expenses. It stores expense records in a CSV file so that data remains saved even after the program is closed.

## Features
- Add new expenses with amount, category, description, and date.
- View all recorded expenses.
- Calculate total expenses.
- Generate category-wise expense summaries.
- Automatically save records in a CSV file.
- Supports custom dates or automatically uses today's date.
- Validates expense amounts and date formats.

## Technologies Used
- Python
- CSV File Handling
- Date and Time Module

## How to Run
1. Download or clone this repository.
2. Open the project folder in VS Code or Terminal.
3. Run the following command:

```bash
python3 main.py
```
